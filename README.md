# Project Elysium

An Autonomous AI Civilization.

## Vision

Project Elysium is a persistent digital world
populated entirely by autonomous AI citizens.

Each citizen has:

- Individual identity
- Personality
- Memory
- Goals
- Decision-making abilities
- Social relationships

Citizens interact with each other and evolve
through their experiences.

## Technology

- Python
- PostgreSQL
- LLMs
- FastAPI
- AI Agent Architecture
